## The line

> I whispered a secret to my smart speaker. My ads now know things my therapist doesn't.

## How it works

`main.ts` (Node 22) writes the line — one fixed string, deterministically — to
`/output/entry.txt`. Two runs write identical bytes.

```sh
node main.ts
cat /output/entry.txt
```
